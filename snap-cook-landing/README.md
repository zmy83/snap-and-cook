# Snap & Cook - Landing Page

## 快速启动

1. 打开 `index.html` 文件即可在浏览器中查看
2. 或者使用本地服务器：
   ```bash
   python3 -m http.server 8000
   ```
   然后访问 http://localhost:8000

## 表单设置

当前表单使用 Formspree（免费）。需要：

1. 访问 https://formspree.io
2. 注册账号
3. 创建新表单，获取表单 ID
4. 在 `index.html` 中替换 `YOUR_FORM_ID`

或者使用其他表单服务：
- Tally.so（免费，无需注册）
- Typeform
- Google Forms

## 部署选项

### 免费部署：
- **Netlify**: 拖拽文件夹即可
- **Vercel**: 连接 GitHub 自动部署
- **GitHub Pages**: 免费托管静态网站

### 付费域名（可选）：
- Namecheap: ~$10/年
- GoDaddy: ~$12/年
